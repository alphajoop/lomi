La politique de confidentialité canonique de lomi. Technologies Africa S.A est sur le site : [lomi.africa/privacy](https://lomi.africa/privacy).

Cette page résume ce qui compte quand vous utilisez la documentation.

## Ce que ce site stocke

- Un cookie de langue (`lomi.language`) pour garder l’anglais ou le français sans préfixe d’URL.
- Des cookies de session Try-it optionnels après une connexion depuis le tableau de bord. Ils ne quittent pas `docs.lomi.africa`.
- Des événements de recherche et d’analytics sans secrets API.

La documentation ne demande jamais de clé secrète live dans le navigateur. Les extraits personnalisés, une fois connecté, n’injectent qu’un secret de **test** (`lomi_sk_test_*`).

## Données Merchant of Record

Les données de paiement, KYC et règlement sont décrites dans la politique du site. Utilisez des clés sandbox pendant le développement.
