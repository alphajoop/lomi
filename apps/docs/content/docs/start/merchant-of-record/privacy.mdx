The canonical privacy policy for lomi. Technologies Africa S.A is on the website: [lomi.africa/privacy](https://lomi.africa/privacy).

This page summarizes what matters when you use the documentation.

## What this site stores

- A language cookie (`lomi.language`) so docs stay in English or French without a locale prefix in the URL.
- Optional docs Try-it session cookies after you connect from the dashboard. Those cookies never leave `docs.lomi.africa`.
- Search and analytics events that do not include API secrets.

Docs never ask for live secret keys in the browser. Personalized samples, when you are signed in, only inject a **test** secret (`lomi_sk_test_*`).

## Data we process as Merchant of Record

Payment, KYC, and settlement data is described in the website privacy policy. Use sandbox keys while you build.
