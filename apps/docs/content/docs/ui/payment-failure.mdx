## Props

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `organizationName` | `string` | Merchant name for the avatar fallback. |
| `organizationLogoUrl` | `string \| null` | Optional merchant logo URL. |
| `title` | `string` | Error heading. |
| `description` | `string` | Supporting copy under the heading. |
| `errorMessage` | `string` | Optional detailed error shown in the red alert box. |
| `retryLabel` | `string` | Retry button label. |
| `onRetry` | `() => void` | Retry action handler. |
| `className` | `string` | Optional extra class names. |
