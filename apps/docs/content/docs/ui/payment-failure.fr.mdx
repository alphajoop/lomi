---
title: Carte d'échec de paiement
description: Un composant à afficher lorsqu'un paiement échoue, avec des options pour réessayer ou contacter le support.
---

Le `PaymentFailureCard` est un composant UI autonome, prêt à copier-coller, construit avec des éléments HTML standard et des classes utilitaires sémantiques Tailwind CSS. Il s'adapte automatiquement à votre thème (mode clair/sombre) et à vos couleurs primaires sans nécessiter l'installation de primitives Shadcn supplémentaires.

## Props

| Prop | Type | Description |
| ---- | ---- | ----------- |
| `title` | `string` | Le titre de la carte d'échec. |
| `description` | `string` | Une description de ce qui s'est mal passé. |
| `errorDetails` | `string` | Détails techniques d'erreur optionnels. |
| `onRetry` | `() => void` | Callback lorsque l'utilisateur clique sur « Réessayer ». |
| `onContactSupport` | `() => void` | Callback lorsque l'utilisateur clique sur « Contacter le support ». |
| `className` | `string` | Classes CSS supplémentaires optionnelles. |
