Cette page est la checklist opérateur pour [lomi. Network](/resources/network). Chaque étape utilise des endpoints déjà supportés avec l'en-tête `Lomi-Account` — pas de routes Network supplémentaires.

<Callout type="info">
  Network est sur invitation. Votre organisation doit être approuvée comme **Opérateur** avant que ces étapes s'appliquent.
</Callout>

## Étape 1 — Compte opérateur et clé API

1. Terminez l'onboarding marchand sur le [tableau de bord](https://dashboard.lomi.africa).
2. Créez une clé API **secrète** pour l'organisation Opérateur (test d'abord).
3. Stockez la clé uniquement côté serveur.

Voir [Clés API](/start/api-keys).

## Étape 2 — Connecter un compte membre

1. Invitez ou liez un compte membre depuis le panneau Network du tableau de bord.
2. Notez l'id public du membre (`acct_...`) — vous l'envoyez comme `Lomi-Account` sur les appels délégués.
3. Confirmez que l'adhésion est **active** pour l'environnement cible (test vs live).

Si l'adhésion est absente ou inactive, l'API renvoie `network_membership_not_found` ou `network_membership_not_active` — voir [Network — erreurs d'autorisation courantes](/resources/network#common-authorization-errors).

## Étape 3 — Accorder des capacités

Les capacités sont par adhésion et environnement. Minimum pour les paiements :

| Capacité | Utilisée pour |
| --- | --- |
| `payment.create` | `POST /checkout-sessions`, `POST /charge/*` |
| `transaction.read_own` ou `transaction.read` | `GET /transactions` |
| `refund.create` | `POST /refunds` |
| `customer.read` / `customer.write` | APIs clients au nom du membre |

Accordez les capacités dans le tableau de bord avant d'appeler l'API. Capacité manquante → `network_capability_missing`.

## Étape 4 — Premier paiement délégué (test)

Créez une session checkout pour le membre :

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/checkout-sessions" \
  -H "X-API-KEY: $LOMI_OPERATOR_TEST_KEY" \
  -H "Lomi-Account: acct_MEMBER_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 1000,
    "currency_code": "XOF",
    "title": "Test Network",
    "success_url": "https://example.com/success",
    "cancel_url": "https://example.com/cancel"
  }'
```

Ouvrez l'URL checkout retournée, payez avec un moyen sandbox, et confirmez via webhook ou `GET /transactions/{id}`.

## Étape 5 — Rapprocher et passer en live

1. Enregistrez les webhooks sur l'organisation **Opérateur** (les événements reflètent l'activité déléguée selon votre configuration tableau de bord).
2. Utilisez `GET /transactions` avec `Lomi-Account` pour le support et la réconciliation.
3. Passez aux clés live et capacités live quand le membre est prêt pour la production.

Voir [Passer en production](/start/go-live) et [Vérifier les paiements](/build/guides/verify-payments).
