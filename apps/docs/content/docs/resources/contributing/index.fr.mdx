## Rôles : développeur, contributeur, opérateur

| Rôle | Qui | CLI / MCP |
| --- | --- | --- |
| **Développeur (intégrateur)** | Ingénieur chez un marchand qui intègre lomi. | **Oui** — public principal de [CLI](/build/cli) et [MCP](/build/mcp) |
| **Marchand (non technique)** | Utilisateur du tableau de bord uniquement | **Non** — utiliser le tableau de bord web |
| **Contributeur** | Contributeur open source au monorepo | **Parfois** — tester les flux d’intégration ; maintenir les packages via [Maintenir la CLI et le MCP](/resources/contributing/maintaining-cli-mcp) |
| **Admin plateforme** | Opérateurs internes `apps/admin` | **Non** |

**Règle :** la CLI et le MCP servent à **intégrer** l’API marchande hébergée. Ils n’exploitent pas la plateforme lomi., l’admin ni l’infrastructure paiement.
