# BNPL product gates

Operational checklist before enabling BNPL for merchants:

1. **Float** — Merchants are credited on plan creation; the platform carries collection risk until SPI installments settle.
2. **SPI** — Payers must be authorized for deferred debit (reject codes AG03 / AM14).
3. **Regulatory** — Align with BCEAO / MoR obligations before marketing BNPL.

**Naming:** Checkout label **JUMBO** + method **BNPL**; ledger uses the same pair. Not the Jumbo MPOS app (`apps/jumbo`).

Canonical technical reference: `apps/api/docs/bnpl-gates.md` in the monorepo.
