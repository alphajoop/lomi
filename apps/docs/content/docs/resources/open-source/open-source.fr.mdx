lomi. suit un modèle **hébergé d’abord**. Les marchands s’intègrent via notre API cloud, le tableau de bord et le checkout. Nous **ne proposons pas** l’auto-hébergement du traitement des paiements à ce stade.

Notre **direction à long terme** est d’ouvrir progressivement le monorepo, davantage d’apps, davantage de code source, et à terme un chemin supporté pour les opérateurs qui s’auto-hébergent avec leurs propres accords prestataires et leur conformité. Ce n’est pas disponible aujourd’hui ; voir la [feuille de route](/resources/open-source/codebase#roadmap) pour ce qui est public maintenant.

Nous publions tout de même du code source pour la transparence et les outils d’intégration (SDK, CLI, plugins, docs). Dans cette logique, nous appliquons une **double licence**.

Le projet est principalement sous **GNU Affero General Public License (AGPL)** : la communauté peut utiliser, modifier et redistribuer le logiciel librement. L’AGPL impose toutefois que toute utilisation en service (SaaS notamment) **publie également le code source**. Si vous souhaitez utiliser **lomi.** sans publier vos modifications (intégration à un produit propriétaire) ou l’exploiter commercialement pour des offres similaires, **une licence commerciale est requise**.

Certains composants relèvent exclusivement de notre **licence commerciale**, pour les entreprises ayant besoin de fonctionnalités additionnelles ou d’une plus grande flexibilité. Ce **double modèle** nous permet de servir à la fois la communauté open source et les partenaires enterprise.

## Qu’est-ce qui est open source aujourd’hui ?

| Domaine | Disponibilité |
| :--- | :--- |
| Plateforme hébergée (API, tableau de bord, checkout, MoR) | ✅ Production, [créer un compte](https://lomi.africa/sign-up) |
| API REST et webhooks | ✅ Hébergé uniquement |
| SDK, CLI, MCP, plugins | ✅ Outils d’intégration (code + packages) |
| Site de documentation | ✅ Open source (`apps/docs`) |
| Tableau de bord marchand, checkout, storefront | 🔒 Produit hébergé (ouverture progressive du code) |
| Admin | 🔒 Propriétaire |

Pour l’organisation du dépôt et la feuille de route, voir la page [Codebase](/resources/open-source/codebase).

<Callout type="warn">
  **Pas d’auto-hébergement aujourd’hui.** Le traitement des paiements repose sur l’infrastructure hébergée de lomi., Merchant of Record, accords prestataires, conformité et stack opérationnelle. Un clone local sert au **développement et à la contribution**, pas à exploiter votre propre processeur de paiement.
</Callout>

## Plateforme hébergée

Pour les paiements en production, utilisez la plateforme sur [lomi.africa](https://lomi.africa/sign-up) : canaux de paiement intégrés, couverture Merchant of Record, mises à jour automatiques et support dédié.

### Comparaison rapide

| Fonctionnalité | Outils open source | Plateforme hébergée |
| :------------- | :----------------: | :-----------------: |
| API REST et webhooks | Intégration sur l’API hébergée | ✅ |
| Canaux de paiement intégrés | - | ✅ |
| Tableau de bord et checkout | - | ✅ |
| SDK, CLI, MCP, plugins | ✅ Outils d’intégration (code + packages) | ✅ |
| Auto-hébergement du stack paiement | À la feuille de route | - |
| Mises à jour automatiques | - | ✅ |
| Support dédié | Communauté | ✅ |

### Options de support

La plateforme hébergée inclut notamment :

- support technique 24/7
- traitement prioritaire des incidents
- aide à la mise en œuvre
