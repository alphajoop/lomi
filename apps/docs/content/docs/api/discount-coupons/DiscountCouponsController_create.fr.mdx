## Aperçu

Créer un coupon

Crée un coupon dans votre organisation. Le code sera automatiquement mis en majuscules.


### Quand l’utiliser

Utilisez pour lancer des promotions ou des remises ciblées par segment.

### Voir aussi

[Récupérer un coupon](/api/discount-coupons/DiscountCouponsController_findOne)


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /discount-coupons`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._


### Paramètres de requête

_Aucun paramètre de requête._


### Corps de la requête

_Pas de corps JSON pour cette opération._


## Réponses

| Statut | Description |
| --- | --- |
| `201` | Coupon créé avec succès |
| `400` | Données invalides ou code déjà utilisé |
| `401` | Clé API invalide ou manquante |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/discount-coupons" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```
