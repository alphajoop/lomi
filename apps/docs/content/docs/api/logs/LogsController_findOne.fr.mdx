## Aperçu

Get a log entry

Returns a single log entry by type and ID. Responds with 404 when the entry does not exist or is outside the API key organization scope.


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /logs/&#123;type&#125;/&#123;id&#125;` (Get a log entry).


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /logs/{type}/{id}`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | — | Log entry UUID |
| `type` | Oui | — |  |

### Paramètres de requête

_Aucun paramètre de requête._




## Réponses

| Statut | Description |
| --- | --- |
| `200` | Log entry details |
| `401` | Invalid or missing API key |
| `404` | Log not found or access denied |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/logs/api_request/value" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
