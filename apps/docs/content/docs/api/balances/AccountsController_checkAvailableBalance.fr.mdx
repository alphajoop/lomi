## Aperçu

Vérifier le solde disponible

Vérifie si le marchand dispose d’un solde disponible suffisant dans la devise indiquée


### Quand l’utiliser

Appelez avant un retrait, un paiement bénéficiaire ou tout flux nécessitant un solde disponible garanti.

### Voir aussi

[Soldes de compte](/api/balances/AccountsController_getBalance) · [Retraits](/api/payouts/PayoutsUnifiedController_create)


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /accounts/balance/{currency}`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._


### Paramètres de requête

_Aucun paramètre de requête._




## Réponses

| Statut | Description |
| --- | --- |
| `200` | Résultat de la vérification de solde |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/accounts/balance/currency_value" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
