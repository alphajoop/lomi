## Overview

List settlement transactions

Returns completed transactions whose `available_at` falls on the settlement date for the given currency.

### When to use this

Drill into a settlement period to reconcile line items against the period totals from [List settlement periods](/api/settlements/SettlementsController_findAll).

### See also

[List settlement periods](/api/settlements/SettlementsController_findAll)


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Integration overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.

## Endpoint

`GET /settlements/{id}/transactions`

The `id` path segment is the `settlement_id` (`{currency}:{YYYY-MM-DD}`). URL-encode the colon (`XOF%3A2026-06-01`) when required by your HTTP client.

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Request

### Path parameters

| Name | In | Required | Schema | Description |
| --- | --- | --- | --- | --- |
| `id` | path | Yes | `string` | Settlement id, e.g. `XOF:2026-06-01` |

### Query parameters

| Name | In | Required | Schema | Description |
| --- | --- | --- | --- | --- |
| `page` | query | No | `integer` | Page number (default `1`) |
| `pageSize` | query | No | `integer` | Page size (default `50`) |

## Responses

| Status | Description |
| --- | --- |
| `200` | Transactions in settlement |

## Errors

**400** for an invalid `settlement_id` format. **401** for auth failures.

## Example

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/settlements/XOF%3A2026-06-01/transactions?page=1&pageSize=50" \
  -H "X-API-KEY: $LOMI_API_KEY"
```
