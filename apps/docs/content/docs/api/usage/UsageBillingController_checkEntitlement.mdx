## Overview

Check customer entitlement

Returns whether a customer has an active entitlement for the given `feature_key`.


### When to use this

Use at request time to gate features without loading full subscription objects.

### See also

[Create entitlement](/api/usage/UsageBillingController_createEntitlement)


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Integration overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.

## Endpoint

`GET /usage/entitlements`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`
