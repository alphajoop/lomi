## Overview

Create or update an entitlement

Defines a plan entitlement feature keyed by `feature_key` for usage or access gating.


### When to use this

Use when feature access is tied to plan entitlements rather than raw meter balance alone.

### See also

[Check entitlement](/api/usage/UsageBillingController_checkEntitlement) · [Usage billing guide](/build/usage-billing)


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Integration overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.
