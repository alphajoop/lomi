## Aperçu

Créer une demande de paiement

Crée une demande de paiement pour un client. Elle a une date d’expiration et peut être suivie jusqu’à réussite ou expiration.


### Quand l’utiliser

Utilisez pour des demandes « payez cette facture » ou POS où le payeur confirme sur son appareil.

### Voir aussi

[Récupérer une demande de paiement](/api/payment-requests/PaymentRequestsController_findOne) · [Transactions](/api/transactions/TransactionsController_findAll)


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /payment-requests`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._


### Paramètres de requête

_Aucun paramètre de requête._


### Corps de la requête

Corps JSON.

Schéma: `object`

| Champ | Obligatoire | Type | Description |
| --- | --- | --- | --- |
| `amount` | Oui | `number` | - |
| `currency_code` | Oui | `enum ("XOF", "USD", "EUR")` | - |
| `description` | Non | `string` | - |
| `customer_id` | Non | `string` | - |
| `expiry_date` | Oui | `string` | - |
| `payment_reference` | Non | `string` | - |
| `metadata` | Non | `object` | - |

Exemple de corps :

```json
{
  "amount": 0,
  "currency_code": "XOF",
  "expiry_date": "string"
}
```


## Réponses

| Statut | Description |
| --- | --- |
| `201` | Demande de paiement créée avec succès |
| `400` | Entrée invalide ou erreur de validation |
| `401` | Clé API invalide ou manquante |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/payment-requests" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"amount":0,"currency_code":"XOF","expiry_date":"string"}'
```
