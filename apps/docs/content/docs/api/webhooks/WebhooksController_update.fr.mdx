## Aperçu

Mettre à jour un webhook

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `PATCH /webhooks/&#123;id&#125;` (Mettre à jour un webhook).


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`PATCH /webhooks/{id}`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._


### Paramètres de requête

_Aucun paramètre de requête._


### Corps de la requête

Corps JSON.

Schéma: `object`

| Champ | Obligatoire | Type | Description |
| --- | --- | --- | --- |
| `url` | Non | `string` | — |
| `is_active` | Non | `boolean` | — |
| `authorized_events` | Non | `array<string>` | — |
| `metadata` | Non | `object` | — |

Exemple de corps :

```json
{
  "url": "string",
  "is_active": true,
  "authorized_events": [
    "string"
  ]
}
```


## Réponses

| Statut | Description |
| --- | --- |
| `200` | Webhook mis à jour avec succès |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X PATCH "https://sandbox.api.lomi.africa/webhooks/id_value" \
  -H "X-API-KEY: $LOMI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"string","is_active":true,"authorized_events":["string"]}'
```
