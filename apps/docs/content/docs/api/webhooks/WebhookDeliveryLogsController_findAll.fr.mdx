## Aperçu

Lister les journaux de livraison

Renvoie les journaux de livraison pour un webhook donné. Ils sont créés automatiquement lors des tentatives d'envoi. Filtrez avec le paramètre de requête webhookId.


### Quand l’utiliser

Utilisez pour diagnostiquer les échecs de livraison webhook et les retries.

### Voir aussi

[Lister les webhooks](/api/webhooks/WebhooksController_findAll) · [Webhooks](/build/webhooks)


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /webhook-delivery-logs`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._


### Paramètres de requête

| Nom | Emplacement | Obligatoire | Schéma | Description |
| --- | --- | --- | --- | --- |
| `offset` | query | Non | — | Nombre de journaux à ignorer (pagination) |
| `limit` | query | Non | — | Nombre maximal de journaux |
| `failedOnly` | query | Non | — | Uniquement les livraisons en échec |
| `successOnly` | query | Non | — | Uniquement les livraisons réussies |
| `webhookId` | query | Oui | — | Filtrer par identifiant de webhook |



## Réponses

| Statut | Description |
| --- | --- |
| `200` | Liste des journaux de livraison |
| `401` | Clé API invalide ou manquante |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/webhook-delivery-logs?offset=1&limit=1" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
