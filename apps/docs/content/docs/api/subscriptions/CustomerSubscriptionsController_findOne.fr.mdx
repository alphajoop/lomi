## Aperçu

Get customer subscription

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /customer-subscriptions/&#123;subscription_id&#125;` (Get customer subscription).


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /customer-subscriptions/{subscription_id}`

URLs de base :

- `https://api.lomi.africa`
