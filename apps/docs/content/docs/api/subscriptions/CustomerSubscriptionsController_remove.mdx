## Overview

Cancel customer subscription

Ends a customer subscription according to platform cancelation rules.


### When to use this

Use when the buyer cancels via your UI or support cancels on their behalf.

### See also

[Update customer subscription](/api/subscriptions/CustomerSubscriptionsController_update)


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Integration overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.
