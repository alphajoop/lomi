## Overview

Remove a scheduled end-of-period cancellation (`cancel_at_period_end`) so the subscription continues renewing.

### When to use this

Use when a customer changes their mind before the current billing period ends.

### See also

[Cancel subscription](/api/subscriptions/SubscriptionsController_cancel)

## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Integration overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.

## Endpoint

`POST /subscriptions/{id}/uncancel`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Request

### Path parameters

| Name | Required | Schema | Description |
| --- | --- | --- | --- |
| `id` | Yes | `string` (uuid) | Subscription UUID |

### Request body

_No request body._

## Responses

| Status | Description |
| --- | --- |
| `200` | Subscription updated |
| `401` | Invalid or missing API key |
| `404` | Subscription not found or access denied |

## Errors

Errors follow the standard JSON error format (status code and machine-readable message). Validate inputs before calling; **401** indicates a missing/invalid key, **404** a missing resource for this organization, **429** rate limiting.

## Example

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/subscriptions/{id}/uncancel" \
  -H "X-API-KEY: $LOMI_API_KEY"
```
