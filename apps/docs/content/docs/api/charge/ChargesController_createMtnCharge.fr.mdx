## Aperçu

Lancer un encaissement direct MTN MoMo

Initie un encaissement RequestToPay MTN MoMo. Avec une clé API **test**, la transaction est marquée terminée dans le ledger sans appel au sandbox MTN.


### Quand l'utiliser

Pour un encaissement MTN initié côté serveur lorsque vous n’utilisez **pas** une session checkout hébergée.

### Bon à savoir

Les encaissements live exigent MTN connecté pour votre organisation et un numéro de téléphone valide. Les remboursements MTN live passent par l’API Disbursement via [Créer un remboursement](/api/refunds/RefundsController_create).

[Encaissement Wave](/api/charge/ChargesController_createWaveCharge) · [Créer un remboursement](/api/refunds/RefundsController_create) · [Transactions](/api/transactions/TransactionsController_findAll)


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /charge/mtn`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres de chemin

_Aucun paramètre de chemin au-delà du motif d’URL._


### Paramètres de requête

_Aucun paramètre de requête._


### Corps de la requête

Corps JSON.

Schéma : `CreateMtnChargeDto`

| Champ | Requis | Type | Description |
| --- | --- | --- | --- |
| `amount` | Oui | `number` | Montant (minimum 1) |
| `currency` | Oui | `string` | Code devise (ex. `XOF`) |
| `customer` | Oui | `object` | Payeur (`name`, `phoneNumber`, `email` optionnel) |
| `description` | Non | `string` | Description du paiement |
| `countryCode` | Non | `string` | Pays ISO 3166-1 alpha-2 (défaut `CI`) |
| `productId` | Non | `string` (uuid) | Produit optionnel |
| `subscriptionId` | Non | `string` (uuid) | Abonnement optionnel |
| `quantity` | Non | `number` | Quantité (défaut `1`) |

Exemple :

```json
{
  "amount": 1000,
  "currency": "XOF",
  "countryCode": "CI",
  "description": "Facture #42",
  "customer": {
    "name": "Jane Doe",
    "phoneNumber": "+2250707070707",
    "email": "jane@example.com"
  }
}
```


## Réponses

| Statut | Description |
| --- | --- |
| `201` | Encaissement MTN initié (RequestToPay) |

## Erreurs

Les erreurs suivent le format JSON standard. **401** : clé invalide ; **404** : ressource introuvable ; **429** : limite de requêtes.

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/charge/mtn" \

```
