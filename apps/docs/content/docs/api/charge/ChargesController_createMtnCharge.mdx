## Overview

Create MTN MoMo charge

Starts a payer-facing MTN Mobile Money RequestToPay charge. With a **test** API key the transaction completes in the ledger without calling the MTN sandbox.


### When to use this

Use for server-initiated MTN collection when you are **not** using a hosted checkout session.

### Good to know

Live charges require MTN connected for your organization and a valid MSISDN. Refunds on live MTN payments use the Disbursement refund API via [Create refund](/api/refunds/RefundsController_create).

### See also

[Create Wave charge](/api/charge/ChargesController_createWaveCharge) · [Create refund](/api/refunds/RefundsController_create) · [Transactions](/api/transactions/TransactionsController_findAll)


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Integration overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.

## Endpoint

`POST /charge/mtn`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Request

### Path parameters

_No path parameters beyond the URL pattern._


### Query parameters

_No query parameters._


### Request body

JSON request payload.

Schema: `CreateMtnChargeDto`

| Field | Required | Type | Description |
| --- | --- | --- | --- |
| `amount` | Yes | `number` | Charge amount (minimum 1) |
| `currency` | Yes | `string` | Currency code (e.g. `XOF`) |
| `customer` | Yes | `object` | Payer details (`name`, `phoneNumber`, optional `email`) |
| `description` | No | `string` | Payment description |
| `countryCode` | No | `string` | ISO 3166-1 alpha-2 country (default `CI`) |
| `productId` | No | `string` (uuid) | Optional product link |
| `subscriptionId` | No | `string` (uuid) | Optional subscription link |
| `quantity` | No | `number` | Quantity (default `1`) |

Example body:

```json
{
  "amount": 1000,
  "currency": "XOF",
  "countryCode": "CI",
  "description": "Invoice #42",
  "customer": {
    "name": "Jane Doe",
    "phoneNumber": "+2250707070707",
    "email": "jane@example.com"
  }
}
```


## Responses

| Status | Description |
| --- | --- |
| `201` | Encaissement MTN initié (RequestToPay) |

## Errors

Errors follow the standard JSON error format (status code and machine-readable message). Validate inputs before calling; **401** indicates a missing/invalid key, **404** a missing resource for this organization, **429** rate limiting.
