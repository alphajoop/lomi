## Overview

Remove a customer

Stops returning the customer in list and detail views for your organization.


### When to use this

Use for GDPR-style deletion requests or when you must disable a buyer record from merchant-facing APIs.

### Good to know

Behavior follows platform rules for retained financial records; confirm with your compliance team for legal holds.


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Integration overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.

## Endpoint

`DELETE /customers/{id}`

Base URLs:
