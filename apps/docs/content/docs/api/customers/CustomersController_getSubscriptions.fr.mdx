## Aperçu

Abonnements d’un client

Renvoie les abonnements d'un client. Réponse 404 si le client n'existe pas ou n'est pas accessible avec cette clé API.


### Quand l’utiliser

Utilisez pour afficher les abonnements actifs d’un client dans le support ou le portail.

### Voir aussi

[Récupérer un client](/api/customers/CustomersController_findOne) · [Abonnements](/build/subscriptions)


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /customers/{id}/subscriptions`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | - | UUID du client |

### Paramètres de requête

_Aucun paramètre de requête._




## Réponses

| Statut | Description |
| --- | --- |
| `200` | Liste des abonnements du client |
| `401` | Clé API invalide ou manquante |
| `404` | Client introuvable ou accès refusé |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/customers/value/subscriptions" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
