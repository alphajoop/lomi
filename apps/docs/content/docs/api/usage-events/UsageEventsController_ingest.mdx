## Overview

Record a usage event

Idempotent usage ingest. Events are processed asynchronously and update meter balances.


### When to use this

Use this endpoint when your flow needs `POST /usage-events` (Record a usage event).


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Integration overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.

## Endpoint
