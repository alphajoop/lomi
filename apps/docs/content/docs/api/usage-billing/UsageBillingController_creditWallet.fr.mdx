## Aperçu

Credit prepaid usage units to a customer meter wallet

### Quand l'utiliser

Utilisez cet endpoint pour `POST /usage-billing/credits` (Credit prepaid usage units to a customer meter wallet).


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint
