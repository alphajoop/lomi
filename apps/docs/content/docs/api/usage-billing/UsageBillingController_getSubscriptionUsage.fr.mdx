## Aperçu

Get meter usage for a subscription

### Quand l'utiliser

Utilisez cet endpoint pour `GET /usage-billing/subscriptions/&#123;subscriptionId&#125;/usage` (Get meter usage for a subscription).


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /usage-billing/subscriptions/{subscriptionId}/usage`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`
